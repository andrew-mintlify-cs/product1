The data load controller orchestrates how data enters the platform. It coordinates initial loads, incremental updates, and reloads across data sources.

## Load types

| Load type | Description |
| --- | --- |
| Initial | Full load when an instance starts. |
| Incremental | Continuous updates as new records arrive. |
| Reload | Full refresh of a table or partition on demand. |
