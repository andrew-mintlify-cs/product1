Product1 is a data analytics platform for building real-time aggregation and query workloads. This section covers the core concepts you need before deploying Product1.

## Architecture

Product1 is composed of three main layers:

- **Engine**: the in-memory aggregation engine that executes queries.
- **Content server**: stores dashboards, saved queries, and user settings.
- **Connectors**: ingest data from databases, object storage, and streaming sources.
